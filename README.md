# 🏛️ Digital CV & Portofolio Interaktif (React.js)
### Fresh Graduate Sarjana Ilmu Pemerintahan (S.IP)

Website portofolio interaktif dan curriculum vitae digital modern yang dirancang khusus untuk mempresentasikan kompetensi di bidang **Analisis Kebijakan Publik, Tata Kelola Pemerintahan (Good Governance), Riset Sosial Humaniora, & E-Government (SPBE)**.

---

## 🌟 Fitur Utama
- **Interactive Policy Brief Viewer**: Modal interaktif untuk membaca ringkasan eksekutif, analisis empiris, dan rekomendasi kebijakan strategis.
- **Dynamic Perspective Switcher**: Simulasi sudut pandang portofolio yang dapat disesuaikan untuk melamar ke posisi:
  1. *Policy Analyst & Researcher* (Think-Tank / Bappeda / Kementerian)
  2. *Public PR & Governance Communicator* (Humas Pemerintah / Media)
  3. *Civic Action & NGO Specialist* (LSM / Organisasi Internasional)
  4. *Digital Gov & GovTech Innovator* (Konsultan SPBE / Smart City)
- **Stateful Category Filters**: Filter cepat berdasarkan *Policy Brief*, *Riset & Publikasi*, dan *Program Publik / KKN*.
- **Quick PDF / ATS-Friendly Export**: Terintegrasi dengan stylesheet cetak otomatis (`window.print()`).
- **Dark & Light Mode**: Desain bertema editorial *Deep Navy & Warm Amber Gold*.

---

## 🛠️ Teknologi yang Digunakan
- **Frontend**: React 18 & Babel Standalone (JSX Component Architecture)
- **Styling**: Vanilla CSS (Custom Design System, Glassmorphism, Responsive Grid)
- **Typography & Icons**: Google Fonts (Plus Jakarta Sans, Playfair Display) & FontAwesome Icons

## 🚀 Cara Menjalankan Secara Lokal

1. **Clone repository ini**:
   ```bash
   git clone https://github.com/USERNAME/NAMA-REPO.git
   cd NAMA-REPO
   ```

2. **Jalankan aplikasi**:
   - Cukup buka `index.html` langsung di browser, atau
   - Jalankan menggunakan server lokal:
     ```bash
     npm start
     ```

---

## 🌐 Deploy Gratis via GitHub Pages
1. Masuk ke tab **Settings** di repository GitHub Anda.
2. Pilih menu **Pages** di sebelah kiri.
3. Pada bagian *Build and deployment > Branch*, pilih branch `main` (atau `master`) dan folder `/ (root)`.
4. Klik **Save**. Website Anda akan langsung online dalam 1-2 menit dengan domain gratis:
   `https://USERNAME.github.io/NAMA-REPO/`
